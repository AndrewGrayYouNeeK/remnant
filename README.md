# REMNANT

You are the crashed mind. You do not walk. You **wear machines**.

Wright Field, 1947. Leap from crate to radio to jeep battery. Stay out of flashlight cones. Get the signal out before dawn.

The clicker in `web/` is a dead prototype. The real game is **INHABIT** (`inhabit/`).

**Repo:** https://github.com/AndrewGrayYouNeeK/remnant

## How it plays

- Tap a glowing object to inhabit it (only in leap range).
- E / the trick button uses whatever you are wearing (beam, ring, kill lights, transmit).
- Three witnesses, a pulled plug, or dawn = warehouse.
- Transmit from the **radio** or **jeep battery** to win.
