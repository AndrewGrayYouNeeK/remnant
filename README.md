# REMNANT

Play as the ancient AI that crashed at Roswell.

**Repo:** https://github.com/AndrewGrayYouNeeK/remnant

## Play

Open `web/index.html` in a browser, or in Cursor: right-click → Open Preview.

Tap the core. Buy rooms that think. Run projects. Cover keeps you hidden. Heat is how they find you.

Progress saves in the browser (`localStorage`).

## Cursor

```
File → Clone Repo → AndrewGrayYouNeeK/remnant
```

Then Open Folder on that clone. See `CURSOR.md`.
